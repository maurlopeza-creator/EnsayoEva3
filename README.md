### Pasos para la Instalación

1.  **Clona el repositorio:**
    ```bash
    git clone [https://github.com/tu-usuario/tu-proyecto.git](https://github.com/tu-usuario/tu-proyecto.git)
    cd tu-proyecto
    ```

2.  **Instala las dependencias:**
    ```bash
    npm install # O el comando equivalente en tu tecnología (pip install -r requirements.txt, etc.)
    ```

3.  **Configura las variables de entorno:**
    Crea un archivo `.env` en la raíz del proyecto basándote en `.env.example`:
    ```bash
    cp .env.example .env
    ```
    *(Asegúrate de rellenar las credenciales necesarias en el archivo `.env`)*

4.  **Inicia el servidor de desarrollo:**
    ```bash
    npm run dev
    ```

El proyecto debería estar corriendo en `http://localhost:3000` (o el puerto que uses).
